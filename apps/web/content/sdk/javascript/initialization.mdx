## Constructor

```ts
new CanaryGate(apiKey: string, options?: CanaryGateOptions)
```

### Parameters

| Parameter | Type                | Required | Description                                                    |
| --------- | ------------------- | -------- | -------------------------------------------------------------- |
| `apiKey`  | `string`            | Yes      | Environment API Key. Created under **Settings → API Keys**.    |
| `options` | `CanaryGateOptions` | No       | Configuration options. See below.                              |

### `CanaryGateOptions`

| Option           | Type     | Default                     | Description                                                              |
| ---------------- | -------- | --------------------------- | ------------------------------------------------------------------------ |
| `userId`         | `string` | Auto-generated              | User ID for rollout hashing. Use a stable ID per user.                   |
| `baseUrl`        | `string` | `https://api.canarygate.io` | API base URL (useful for self-hosted environments or proxies).           |
| `staleThreshold` | `number` | `60000`                     | Time in ms without sync before considering stale.                        |

## `init()`

```ts
await canary.init()
```

Executes two actions in sequence:

1. Makes an HTTP fetch to load all flags for the environment
2. Opens the SSE connection to receive real-time updates

Always `await` `init()` before reading flags — otherwise, `getFlag()` may return `undefined` before the initial load completes.

## Examples

### Browser (React)

```tsx
import { CanaryGate } from '@canarygate/js'
import { useEffect, useRef } from 'react'

export function useCanaryGate(userId: string) {
  const ref = useRef<CanaryGate | null>(null)

  useEffect(() => {
    const client = new CanaryGate(process.env.NEXT_PUBLIC_CANARYGATE_KEY!, {
      userId
    })

    client.init().then(() => {
      ref.current = client
    })

    return () => {
      client.disconnect()
    }
  }, [userId])

  return ref
}
```

### Node.js (singleton)

```ts
import { CanaryGate } from '@canarygate/js'

let client: CanaryGate | null = null

export async function getCanaryGate() {
  if (!client) {
    client = new CanaryGate(process.env.CANARYGATE_KEY!)
    await client.init()
  }
  return client
}
```

### One-shot script (no SSE)

```ts
import { CanaryGate } from '@canarygate/js'

const client = new CanaryGate('cg_api_key')
await client.init()

const flag = client.getFlag('run-migration')
if (flag?.enabled) {
  await runMigration()
}

// Close the SSE connection so the process can exit
client.disconnect()
```

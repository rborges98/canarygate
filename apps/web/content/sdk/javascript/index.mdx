The `@canarygate/js` SDK is the official client for integrating CanaryGate into JavaScript and TypeScript applications.

## Compatibility

| Environment                                    | Support      |
| ---------------------------------------------- | ------------ |
| Browser (modern)                               | ✓            |
| Node.js 18+                                    | ✓            |
| Deno                                           | ✓ (via npm)  |
| Bun                                            | ✓            |
| Edge Runtime (Cloudflare Workers, Vercel Edge) | Partial\*    |

\*Edge runtimes have limited `EventSource` support — SSE may not work. Use `disconnect()` immediately after `init()` in those environments.

## Installation

```bash
npm install @canarygate/js
```

## Full API

| Method                             | Description                                    |
| ---------------------------------- | ---------------------------------------------- |
| `new CanaryGate(apiKey, options?)` | Creates the client                             |
| `init()`                           | Loads flags and starts SSE                     |
| `getFlag(key)`                     | Returns `FlagData \| undefined`                |
| `getFlags()`                       | Returns `FlagData[]` (all flags)               |
| `isStale()`                        | `true` if the connection is degraded           |
| `getLastSyncAt()`                  | `Date \| null` of the last sync                |
| `disconnect()`                     | Closes the SSE connection                      |
